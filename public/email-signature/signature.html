Cómo usar la firma

  • Mac Mail: Mail → Ajustes → Firmas → selecciona hi@raulyn.com → arrastra el recuadro mint de abajo a la zona de firma (o copia/pega desde Safari).
  • iPhone: Ajustes → Mail → Firma → pega el mismo bloque (después de copiarlo en Mac).
  • Gmail (web): Configuración → Ver toda la configuración → General → Firma → pega el bloque mint. Si pierde formato, usa la imagen signature-fallback.png y enlaza manualmente.

Enlaces sociales editables en el HTML (WhatsApp / Instagram). Tras publicar el sitio, las imágenes cargan desde https://www.raulyn.com/email-signature/.
